# HollyWorld GoldenSpawner

Мод для Forge 1.16.5, показывает расширенную информацию о Золотом Спавнере на сервере HollyWorld.

## Возможности

- **Тултип спавнера:** моб, меч с зачарованиями, количество убийств, шанс поломки
- **Подсветка в инвентаре:** фиолетовая — обычный спавнер, зелёная — с мечом
- **Инфо-панель:** серверная информация — цена, продавец, аукцион, лот
- **Фильтрация лора:** убирает служебные строки сервера («Особености», буллеты)

## Установка

1. Установи [Forge 1.16.5](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.16.5.html)
2. Скопируй `goldenspawner-1.0.0.jar` в папку `mods`
3. Запусти Minecraft

## Сборка

```bash
./gradlew build
```

JAR будет в `build/libs/goldenspawner-1.0.0.jar`
